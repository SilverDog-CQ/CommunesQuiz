Objet du site

CommunesQuiz est un jeu de géographie consacré aux communes françaises. Il permet de tester ses connaissances des communes françaises à partir d'une carte interactive.

Données de progression

CommunesQuiz utilise le stockage local du navigateur (localStorage) afin de conserver la progression de la partie sur l'appareil utilisé.

Les données de progression sont enregistrées localement dans le navigateur. Aucun compte utilisateur n'est nécessaire pour utiliser le jeu.

Import et export des parties

La fonction « Importer / Exporter » permet d'enregistrer une progression dans un fichier et de la restaurer ultérieurement.

Les fichiers exportés sont créés directement dans le navigateur de l'utilisateur et les fichiers importés sont lus localement par le site.

Vie privée et données personnelles

CommunesQuiz ne demande pas la création d'un compte et ne collecte pas volontairement de données personnelles par l'intermédiaire d'un formulaire ou d'un espace membre.

La progression d'une partie est conservée dans le stockage local du navigateur et n'est pas envoyée à CommunesQuiz.

Le site étant hébergé par GitHub Pages, GitHub indique que l'adresse IP des visiteurs peut être enregistrée et conservée à des fins de sécurité.

Pour plus d'informations sur le traitement des données par GitHub : Déclaration de confidentialité de GitHub

Cookies et traceurs

CommunesQuiz n'intègre actuellement aucun outil de publicité, de suivi comportemental ou de mesure d'audience dans son code.

Le site utilise en revanche le stockage local du navigateur afin de conserver la progression de la partie.

Ressources externes

Le site utilise certaines ressources externes nécessaires à son fonctionnement ou à son affichage, notamment la police Rubik fournie par Google Fonts et la bibliothèque JavaScript proj4 distribuée par jsDelivr.

Données utilisées par le jeu

Les données utilisées par CommunesQuiz comprennent notamment les noms des communes, leurs coordonnées géographiques et leurs données de population.

Données de population : Insee, recensement de la population 2023.

Coordonnées géographiques : OpenStreetMap et ses contributeurs, sous licence ODbL.
